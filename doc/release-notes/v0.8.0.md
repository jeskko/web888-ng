KiwiSDR clients: kiwirecorder, SuperSDR and other Kiwi software can use a
web888d receiver.

* **The KiwiSDR protocol** on the web port (8073), next to web888d's own
  UI (`doc/m5-kiwi.md`):
  * **Audio** in USB, LSB, CW, AM, SAM (SAL, SAU, SAS) and IQ, as plain
    16-bit PCM or ADPCM-compressed. Each audio stream takes a receiver
    channel, as a web listener does.
  * **The waterfall** at Kiwi's zoom levels, plain or compressed, from
    the same shared views as the web UI. It works next to an audio stream
    or on its own (kiwirecorder `--wf`).
  * **`/status` and `/VER`** answer as on a Kiwi.
  * Kiwi users show in the user list (with the name they give) and in the
    admin's session list.
* **Tried with** kiwirecorder and SuperSDR against a Web-888 with real
  signals. 40 m FT8 recorded through kiwirecorder decodes as well as the
  receiver's own FT8 skimmer for the same slots.
* **Behaviour to know:**
  * When every channel is taken, a Kiwi client is told the receiver is
    busy (Kiwi clients don't queue). kiwirecorder retries every 15 s.
  * With a listener password set, Kiwi clients send it as their password
    (kiwirecorder `--pw`). The admin password gives the admin's class.
  * The per-address limit (`[limits] per_ip`, 4 by default) applies.
    For a host running many recorders, as wsprdaemon does, add it to
    `[limits] trusted`.
  * The session time limit applies; the idle limit doesn't (a recorder
    never tunes).
* **Configuration**, also in the admin pages:

  ```toml
  [kiwi]
  enabled = true
  name = ""               # empty: "web888d <callsign>"
  location = ""
  smeter_offset_db = 0.0  # dBm = dBFS + this
  ```

  web888d measures levels in dBFS. Kiwi clients get dBm = dBFS +
  `smeter_offset_db`, for the S-meter and the waterfall. It isn't
  calibrated yet. The project's Web-888 uses -12 dB for now, an estimate
  from band noise; a measurement with a known signal is to come.
* **Not included:** camping on another user's stream, Kiwi extensions,
  the Kiwi browser UI, NBFM (falls back to AM, as on a Kiwi), and GPS
  timestamps in IQ (they wait for the open FPGA's timestamps).

The receiver's location for Kiwi clients comes from `[station] locator`.

This version has run on a Web-888 since 2026-11-11 (the channelizer
bitstream, FT8 skimmers on ten bands).
